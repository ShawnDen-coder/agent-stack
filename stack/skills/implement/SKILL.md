# Implement

Read the relevant implementation and tests before editing. For a bug, establish a reproduction or a failing boundary check when practical. Make the smallest coherent change that satisfies the accepted scope, preserves user work, and follows the repository's architecture.

Exercise meaningful edge cases and failure paths. Keep unrelated changes out of the patch and avoid claiming behavior that has not been implemented.
