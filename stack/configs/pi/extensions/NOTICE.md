# Herdr Pi integration

`herdr-agent-state.ts` is the unmodified bundled Pi integration from Herdr
v0.9.5, commit `2ecf19a92fc3a7fff75b6ce3655ef04f4625ec01`, integration
version 9. Source:
https://github.com/herdrdev/herdr/blob/2ecf19a92fc3a7fff75b6ce3655ef04f4625ec01/src/integration/assets/pi/herdr-agent-state.ts

mode. Its presence alone does not establish that state reporting works.
